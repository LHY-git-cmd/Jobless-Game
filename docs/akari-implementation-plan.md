## 范围与技术选型声明

沿用现有原生HTML/CSS/JavaScript、FastAPI、MySQL及Flyway，不增加框架或常驻服务。恢复新版照明选关，提供入门及第1～15关；界面不显示难度系数。保留截图中的深蓝、暖金和灯泡素材，三项规则全部满足后才通关。时间只记录，不限制通关，不要求最少灯泡。

最高优先级：先用独立搜索确认唯一解，再用可复现逻辑推理验证题目。在线请求只校验终盘，不运行求解器。无数字的棋盘只要存在互相可见的白格便存在多组极大合法灯位，不能保证唯一解，因此入门和第1关补充少量0/1提示。

每关固定不同题目，离线保存唯一性和逻辑推理审计；难度结合实际推理层级、依赖及操作量筛选，不只按尺寸排序。入门逐步学习放灯、撤灯和规则；前5关显示对应短说明，后续保留规则按钮。
