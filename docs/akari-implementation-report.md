# 照明入门及15关实施报告

日期：2026-10-22（北京时间）。状态：本地实现、浏览器验收及隔离MySQL/Flyway验证完成，未部署生产。前文记录首版，最新七步教学及第10～15关10×10补充见文末。

## 实际功能

新版入口为 `journey.html?game_id=akari`。提供入门及第1～15关，尺寸按已确认方案从4×4逐步增加到10×10；只显示关卡编号，不显示难度系数。沿用深蓝面板、暖金按钮、未亮的蓝紫格、暖黄光线及原灯泡素材。

入门用两个必要的数字1和两段光路，依次练习放灯、撤灯、完成全盘。前5关提供短说明。所有关卡支持放灯/撤灯、数字超额与灯泡互照标红、全亮但数字未满足时的明确文字反馈。只有覆盖全部白格、数字准确且灯泡无互照才自动提交。

普通通关固定3星，入门固定1星、2经验；时间仅记录，不限时、不因思考较慢降星、不要求最少灯泡。普通关沿用原有奖励里程碑，全部首次通关共46星、1202经验。重复成绩不重复发奖。新版第1关授予原照明永久资格，旧题目、旧尝试与旧成绩保留。

支持规则弹窗暂停、返回选关暂停、隐藏及离页暂停、每关独立草稿、刷新核验续玩、重开确认、待结算冻结与断网后同一负载重试、通关下一关。第15关按钮返回选关；只有全部16关都有正式成绩才显示全部点亮。账号退出或切换后，旧响应不再回填棋盘或发奖。

## 题库与逻辑递进

新增冻结文件 `backend/content/akari-catalog-v2.json`、独立审计 `akari-audit-v2.json` 及离线工具 `backend/akari_content.py`。独立的最多取两解搜索验证所有16题唯一。标准答案及推理审计不经公开目录、开始接口或前端模块下发；请求内只进行有界终盘校验。

入门至第6关可由直接数字、视线互斥与覆盖约束解完；第7～12关必须增加联合约束，直接规则会停滞；第13～15关需要单层矛盾反证，联合约束也会停滞。反证只在某个假设推出矛盾时使用相反结论，不以猜中答案作为推理。固定顺序的推理记录可复现，内部排序按技巧层级、步骤量及白格量递增。

这是首版工具下的可复现递进，不宣称每个玩家的实际耗时严格递增，也尚无人类试玩标定。完全无数字且含互相可见白格的棋盘无法保证唯一解，因此入门及第1关保留数字提示。
