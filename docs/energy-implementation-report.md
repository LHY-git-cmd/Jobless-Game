# 账号体力与首页记录面板调整实施报告

日期：2026-10-23（北京时间）。状态：本地实现和专项验收完成，未部署生产。

后续变更（2026-10-26）：当前上限为10点，新增V20默认值迁移，并修复生产autoflush=False时通关返还余额被后续查询覆盖。下文保留初版实现与当时的测试记录，不代表当前生产模式已无返还缺陷；最新复现、修复和验证见 [10点体力与返还修复](./energy-ten-refund-fix.md)。

## 实际行为

扫雷、照明、数独共用账号体力，初始及上限均为5点。普通新局成功创建时扣1点，该次正式通关返1点；入门免费、不扣也不返。重玩已通过的普通关仍先扣后返，星星和经验继续按原规则计算。继续、刷新、查看规则或取消开始确认不重复扣。

每30分钟按服务器真实时间恢复1点，离线和暂停期间照常累计，最多恢复到5点。已满时停止累计恢复进度，再次消耗后重新计时；未满时继续消耗不重置周期。通关返还达到5点时清空剩余周期。免费教学和升级前没有支付体力的旧尝试不能额外返还体力。

重新开始不返旧局消费，并再扣1点。新增原子重开接口把旧局结束、新局创建和扣除放入同一账号事务；体力不足、并发冲突或创建失败时全部回滚，旧棋盘及输入保留。开始和重开使用独立的幂等键空间，重复请求、重复终盘、同UUID跨资源请求都不会重复扣返。另一个标签页已经重开的旧局不能再生成第二份收费尝试。

头像旁新增体力图标、当前值/5及下一点恢复倒计时。余额由服务器快照决定，倒计时本地显示，不在浏览器自行增加体力。恢复节点核对一次服务器，不逐秒请求；恢复请求失败30秒退避，保持已知余额。账号更换废弃旧读取，旧修订或旧取样快照不能覆盖新余额。开局和通关直接更新体力，不等待星星动画。

首页“我的通关记录”整个展示面板及初始化已删除，介绍区恢复单列布局。没有删除账号历史数据、星星、经验、等级、关卡进度或排行能力。新增样式单独使用 `styles/components/energy.css`，原公共样式冻结基线保持不变。三游戏普通开始和重开说明体力规则，入门明确免费；隐藏的主题面板不再并发读取主题资料，减少游戏恢复和账号体力加载时对四个数据库执行槽的争用。

## 数据与接口

- `player_energy`：每账号一行，保存余额、下次恢复时间及修订号。
- `attempt_energy`：每个付费尝试一份扣返凭证，尝试清理时通过外键级联回收，免费及历史尝试不补建收费凭证。
- `GET /api/v1/me/energy`：当前账号的权威体力和恢复时间；在用户锁内结算自然恢复。
- `POST /api/v1/attempts/{id}/restart`：空JSON、UUID幂等键，原子重开当前关卡最新版本。
- 开始、尝试读取和通关表示包含体力快照；历史完成快照保留原始修订，前端拒绝其覆盖较新的体力。

新增Flyway V15创建两个表，不修改旧迁移。恢复使用惰性时间结算，无后台扫描、额外常驻服务或新增队列。现有用户事务锁串行同账号操作，保持数据库及执行器资源边界。
