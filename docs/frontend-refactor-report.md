## 实际变更

1. 游戏入口 `main.js` 从 981 行缩减为 4 行，仅创建应用实例。
2. 首页、三关棋盘/交互、结果与结算弹窗、存档协调分别抽离。游戏控制器协调账号、当前关卡、规则计时、轮次验证与通关保存；各关拥有自己的棋盘，通过回调连接共享流程。
3. 新模块通过工厂显式创建实例，导入时不访问页面或发起请求。资源作用域清理事件、计时器和设置订阅；实例销毁保存快照并废弃请求轮次，阻止旧回包修改页面。
4. 页面固定节点通过语义名称集中映射；动态评论/回复仍在对应组件范围内查询。跨模块事件名集中于 `lib/events.js`，包含认证过期和授权开始事件。
5. `lib/http.js` 统一同源 Cookie、十二秒独立超时、JSON/204、状态码与错误元数据。认证保留 AuthError/字段和用户校验，论坛保留 Retry-After/账号隔离，挑战保留轮次/快照/原负载重试。公共请求不自动重试写操作。
6. 生产 HTML/JS 引用中的 JS/CSS 手动版本号已移除。Docker、宝塔模板及本地 FastAPI 对代码和页面使用 no-cache；音频与图片沿用素材缓存，API 继续 no-store。修正离线打包器，避免重复插入 assets location。

保持多页地址、既有游戏规则和存档版本。未增加框架、构建工具、依赖、常驻服务、API 协议或数据库迁移。
