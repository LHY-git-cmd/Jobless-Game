## 数据与接口

- users.avatar_id：TINYINT UNSIGNED NOT NULL DEFAULT 1。ORM 使用 SQLite 类型变体仅供隔离回归。
- 登录、/api/auth/me、榜单行增加 avatar_id。
- PUT /api/auth/avatar 仅接收严格整数 avatar_id；按静态清单校验，通过当前 Cookie 确定账号，不接收 user_id。
- 图片清单同时供前后端读取；头像不写入历史成绩快照。更换头像不重置棋局、音量或个人记录。
- 图片失败回退默认头像；默认图片也失败时保留占位，不无限重试。
