# 扫雷多关卡 MVP 实施报告

日期：2026-10-21。状态：代码与本地验收完成，可通过开发机正在运行的服务预览。

## 效果与范围

入口：`frontend/mine-practice.html`。开发机预览为 `http://127.0.0.1:8001/mine-practice.html`，首页底部加入“新体验：扫雷三档练习，独立续玩”。

- 三个10×10档位：浅滩初探/10雷、林间寻路/15雷、礁石挑战/20雷，均可直接进入。
- 各关分别保存棋盘、选中位置、标记、规则窗口状态及原始起止时间；切关不重开，重开只清空当前关。
- 明确确认规则后才计时，重看规则/切关/离开期间继续累计，通关或失败后冻结。首次规则不能通过 Esc 绕过确认。
- 刷新回到上次所选关卡；失败恢复直接展示全部地雷终盘，不重复播放爆炸。
- 游客无需登录；账号与游客使用独立存储键，游客进度不自动合并到账号，退出登录恢复游客原进度。
- 新成绩仅用于本地练习，不提交正式挑战/排行。旧 `jobless-progress-v1:` 存档保留且不改写，也不自动复制到练习页。
- 选关卡展示状态和各关用时；开始后定位到棋盘，棋盘顶部可返回选关。320/375px界面不横向撑宽，棋盘在自身容器滑动。

扫雷规则和现有控制器被复用。规则新增配置参数并保持原调用默认10×10/10雷，控制器按当前列数计算位置和按雷数生成失败提示。练习页不引入框架、依赖、API修改、数据库迁移或其他游戏重构。

回退可移除首页练习入口及练习页资源，默认正式游戏API/存档格式未变。不要删除玩家正式存档；本地练习键独立使用 `jobless-mine-practice-v1:` 前缀。
