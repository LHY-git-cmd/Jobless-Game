# 数独五档玩法实施报告

日期：2026-10-22（北京时间）。用户已确认计划并授权实现，本地功能、专用数据库及浏览器验收已完成；未部署生产。

## 实际交付

`journey.html?game_id=sudoku` 已恢复正式数独选关。五档共13题：入门为4×4、2×2宫的五步教学，简单、中等、困难、地狱各3道9×9固定题，全部自由选择，开始时需登录。教学依次实际填写、清除、记录笔记、列定位、宫定位，服务端验证步骤及完整终盘后才授予1星2经验。

普通档三星/二星时限分别为5/10、10/20、20/40、35/70分钟，含边界；超时仍可通关得1星。每关逐星累计经验分别2/4/6、3/6/9、4/8/12、5/10/15，按历史最高成绩补差。13题全部满星为37星128经验；重复、并发及丢响应重试不会重复增加成长。

游戏画面以用户参考图为准：深蓝面板、暖金按钮、纸色棋盘、深色给定数、蓝色玩家数字、浅绿行列宫关联、绿色同数、金色选格及红色冲突。支持手动候选笔记、清除、只检查重复/剩余格的进度检查、方向键和数字键输入；键盘重绘保留焦点。手机数字键换行，320/375px和横屏保持完整棋盘且无页面横向溢出。错误可修改，无次数失败及答案提示。

普通题不显示教学目标框；教学只标出当前目标。暂停层遮住棋盘并禁止输入。规则弹窗（含Esc关闭）、返回选关、真实标签切换、跨页和刷新使用服务端暂停时钟。多原因暂停、命令重试和修订冲突沿用现有协议；教学最后一步与离页暂停交错导致终盘提交受阻时，重试先恢复服务器时钟再提交相同终盘。

星级随有效用时递减，结算后以服务器成绩为准；只将本次新增星数汇入顶部总数，支持减少动画。恢复历史结果不重播汇聚动画。换号/退出立即移除旧棋盘及笔记DOM，异步响应和动画均绑定原身份。

## 题库和数据

- `backend/sudoku_content.py` 为开发机离线构造与分级器，不进入在线请求。使用固定种子20261022筛选题目，唯一性由独立MRV搜索最多两解验证，求解分级不使用回溯。
- 简单只用裸单候选；中等必须需要隐藏单数；困难需要数对或区块排除；地狱支持X-Wing、XY-Wing和强链二染色。每题都必须在低档技巧集合中停滞，再由本档技巧逻辑解完。本批3道地狱题均有强链记录，并且禁止强链时不能完整解出。
- `sudoku-catalog-v2.json` 保存13项冻结题目及奖励；`sudoku-audit-v2.json` 保存分级器版本和完整逐步记录。审计重演技巧并独立核对唯一答案，拒绝伪造填数和错误候选排除。测试同时排除数字重命名及旋转/镜像重复题。
- 分级是固定技巧顺序下的可复现结果，不宣称排除了全部其他人类捷径。评分时限为用户确认的首版产品参数，尚未进行大规模人类试玩统计。
- Flyway V12新增13项，真实MySQL已验证数据库冻结定义与源文件一致；旧迁移、历史数独、扫雷定义和永久资格保留。新简单第1题满足原数独资格，教学不授资格。
- 4×4/9×9终盘分别严格验证16/81格、整数范围、给定数及全部行列宫。公开目录不发题，开始后只给题目，不返回答案及审计推理。旧单关开发答案已隔离在legacy，正式页面导入链不包含它。
- 普通中间答案、笔记和模式保存在当前浏览器，按账号、游戏、关卡、尝试、版本和摘要隔离，先GET核验正式资源再恢复。教学中间步骤另有服务端权威状态。不同浏览器的普通未完成答案不自动同步。
- 第一次被服务端成功接收并验证的完整终盘决定用时；响应丢失可按相同负载重放。若终盘从未抵达服务端，则重试之前可能继续累计活动时间，页面冻结的待提交时间不作为自报依据。强杀浏览器或离页断网时，keepalive暂停无法保证到达。

## 本地体验和发布

独立预览地址：`http://127.0.0.1:8003/journey.html?game_id=sudoku`。

在项目根目录运行：

```text
python artifacts/frontend/verify_sudoku.py --preview --port 8003
```

预览仅监听本机，数据位于忽略的 `artifacts/frontend/sudoku-preview.sqlite3`，与其他预览账号隔离；正常登录流程可创建测试账号。原8001/8002/8080服务未停止或替换。

复验入口为 `python artifacts/frontend/verify_sudoku.py`、`python artifacts/frontend/verify_sudoku_interactions.py`；离线题库默认核验运行 `python -m backend.sudoku_content`，已有版本拒绝重新生成覆盖。

生产需要备份目标库，在维护窗口应用尚未执行的Flyway迁移至V12，成套更新前后端并重启API，正式游戏需 `PROGRESSION_ENABLED=true`。尚未进行目标2核2GB服务器资源、容量、生产HTTPS及实际发布验收，桌面专项验证不代表这些项目通过。
