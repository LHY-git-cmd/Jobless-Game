# 扫雷多关卡 MVP 计划

日期：2026-10-21。用户已授权实施 MVP，沿用已确认的扫雷试点范围。

状态：实现与本地验收完成，见 [实施报告](./mine-multilevel-mvp-report.md)。

技术选型：原生 ES Module、独立练习页、现有扫雷控制器与音效；最高优先级是验证关卡身份和进度隔离。先提供 10×10、10/15/20 颗雷三个练习档位；使用稳定 ID 与版本。保留原正式入口及旧存档，新练习成绩只保存在本浏览器，不写正式挑战/排行榜。

步骤：先写规则参数化和独立存档契约并观察失败；实现关卡目录、账号/游客隔离的本地存档；复用棋盘控制器完成选关/规则/重开/结果交互；真实浏览器验证刷新、切关、计时、窄屏、键盘与成绩隔离；完成中文功能提交并提供可访问预览。

验收：三个档位准确布雷；首次确认才计时，切关和离开继续累计，终盘冻结；每关棋盘/标记独立，重开仅影响当前关；刷新返回上次关卡，游客与账号隔离；损坏/禁用存储可降级；正式存档不被改写；不触发挑战写接口。

界面沿用海岛深蓝/暖金风格，三张选关卡直接展示雷数、进度和用时。保留清楚的规则确认与本地练习提示；移动端棋盘在自身容器内滚动。用户已有 index.html 修改保留，提交只包含新增入口。
