# 三模式竞技大厅与成长策略实施报告

日期：2026-10-23（北京时间）。按用户确认的竞技大厅计划实现；本地预览已开启，未部署生产、未迁移业务MySQL。

## 最终行为

- 公共账号、体力与导航沿用闯关模式；大厅为本人头像/用户名、VS、对手头像或加号，模式选择、匹配/准备按钮及时间区域。
- 搜索公开ID或完整用户名，只能邀请在线、空闲且已达5级的玩家；对方接受后入房，拒绝/取消/过期均有明确反馈。普通页面可收到接受/拒绝邀请弹窗，竞技页显示邀请区。
- 单人可开始或取消匹配；三种模式独立FIFO队列：扫雷10×10/10雷、照明约第10关难度独立10×10题池、简单9×9数独独立题池。
- 配到对手不会自动准备；双方明确准备后统一3秒倒计时，开始前不发题。好友房主可在等待时切换模式并清空准备，匹配房模式锁定。
- 时间显示匹配等待用时或比赛用时。比赛上限10分钟，不允许暂停；1秒内均有效完成为平局。踩雷、开局后主动退出或单方断线超过30秒判负；双方断线或服务重启作废。
- 扫雷雷区仅在服务器，双方0号格安全起点及布局相同，各自揭格独立。踩雷与退出按HTTP接收顺序处理，避免数据库任务先后反转即时失败结果。
- 初始100竞技积分，胜+20、负−10，可为负分；好友及匹配都计分。平局、双方超时或作废不加扣。每局每人唯一流水与结果同事务提交，竞技不扣体力、不发闯关星数和经验。
- 积分榜已接实际余额降序，同分并列且分页有界；未入房初始化的账号不伪造入榜。
- 等级1～6累计经验为0/18/36/54/72/90，72经验达到5级解锁竞技。历史经验保留，只重新按统一曲线显示等级。
- V18追加普通关奖励版本：首次三星仅将当局实际新增经验翻倍。基础2/4/6的关卡直接首次三星得12、一星后首次三星得8、二星后首次三星得4；重复三星0，历史已三星不补发，入门不适用。旧尝试继续绑定旧规则。

## 实现边界与资源

沿用原生JS/HTML/CSS、FastAPI、MySQL、REST写操作和SSE修订通知，不增加常驻服务。大厅新增单次快照读取，减少账号成长、体力及竞技请求抢占四槽数据库执行器。双方同时准备遇到412时重读并重放本人原意图，不反向取消准备。

在线可达租约与比赛连接分开，普通页面心跳不能延长比赛30秒断线宽限。跨标签合并在线读取；租约索引上限4096账号，每账号最多4会话。邀请全局最多32条、同目标8条、同发送者1条，60秒超时；仍沿用4房/8排队/16事件流上限。对局与邀请终态有界回收，永久积分流水和历史成长保留。

照明/数独竞技题由离线空间/数字变换产生，验证唯一解并与闯关实际题盘区分；难度类别沿用源题，尚未做真人用时校准，不宣称严格反作弊。固定小题池存在熟题风险，后续可在冻结版本机制下扩充。
