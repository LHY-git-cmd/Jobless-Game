# 历史前端实现

这里保留已下线的三关单页流程、旧扫雷九关练习、对应控制器及旧本地存档兼容逻辑。当前HTML入口不导入本目录，也不恢复旧游戏入口。

- `game/`：旧三关控制器、挑战客户端、会话、存档、结算及首页展示工厂。
- `mine/`：旧本地扫雷规则、棋盘控制器、九关目录与练习存档。
- `auth-game.js`、`auth-page.js`：旧页面装配参考。

保留原因：`frontend/test/legacy/` 继续验证旧存档、幂等负载、账号隔离和销毁语义；不能因当前页面不可达就删除玩家的历史状态或兼容规则。

历史 `completion` 测试使用 `test/fixtures/legacy-game.html` 固定DOM，而非依赖已经重制的当前首页。该夹具不含脚本，并由Docker构建白名单和离线发布包规则排除。

新增业务请放在 `pages/`、`features/`、`games/` 或 `shared/`，不要继续向本目录增加当前页面依赖。
