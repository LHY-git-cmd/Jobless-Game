# 无职游戏

远程仓库：[LHY-git-cmd/Jobless-Game](https://github.com/LHY-git-cmd/Jobless-Game)。

手机端优先的三关网页游戏。入口采用海岛背景与关卡素材，棋盘和弹窗使用统一的深蓝、暖金色界面。

设计、开发与部署前请阅读 [项目硬约束](./README-CONSTRAINTS.md)，其中明确了 2 核、2GB 内存与宝塔共存的资源边界，以及后续登录功能的账号、迁移和验收要求。

完整目录结构与文件夹用途见 [项目目录树](./PROJECT-TREE.md)。后续目录结构、所列文件或用途变更时，必须同步更新该文档。

后端按控制层、业务层、数据访问层、模型层和公共层组织，调用方向为 Controller → Service → Repository。层级职责和扩展约定见 [后端架构说明](./backend/README.md#五层架构)。

顶部导航按“排行榜 / 无职游戏 / 论坛”排列。排行榜提供三关总榜和扫雷、照明、数独三个独立分榜；论坛仍为占位页面。

- 第一关：10 × 10 扫雷，10 颗雷。进入游戏时显示规则弹窗，先点选格子，再按“标记”或“排雷”。
  踩雷后按距离依次显示、引爆全部地雷，播放裁剪后的爆炸音效；连锁结束再显示结果。可关闭音效，重新开始或返回首页会停止动画与声音。音效从 `source/audio/爆炸声.flac` 的 0.045～1.445 秒裁剪，保留起爆与短尾音并淡出，处理脚本为 `source/audio/prepare_explosion.py`。
- 第二关：固定题盘照明，10 × 10 格、唯一解。点击白格放灯，再次点击撤灯，照亮全部白格且满足数字黑格即可通关。手机上可在棋盘区域滑动。
- 第三关：固定题盘数独，34 个已给数字、唯一解。进入数独时显示规则弹窗，可点格填数、清除和检查进度。

每轮必须从第一关扫雷开始，通关且成绩成功保存后解锁照明，再解锁数独；首页第二、第三关入口显示锁定状态。未登录时先打开登录弹窗，成功后进入扫雷规则弹窗。用户名不存在时自动创建账号，已有账号必须验证原密码。各页右上角提供登录、用户名和退出入口，刷新或跨页可恢复登录会话；进行中的棋局不会保存，游戏逻辑仍在浏览器执行。每个账号同时只有一轮有效挑战，新开一轮使旧轮次失效。

三关从首次有效操作起计时，重新开始只重置当前关及后续关卡的本轮状态，前序已通关用时保留。规则阅读与通关后查看棋盘、关卡间停留不计入用时。每关通关立即保存，失败时保留终盘并允许重试，不提前解锁下一关。最后一关完成并保存后先显示祝贺，点击“开始结算”按扫雷、照明、数独顺序展示通关时间及合计，并可查看排行。返回首页会清空本轮状态，不删除已经保存的历史成绩；完整结算后再次挑战从首页开启新一轮。

总榜只使用同一轮完整三关的最好总时长，不拼接不同轮次的单项最好成绩。三个分榜分别使用对应游戏的历史最短通关时长，同秒并列（1、1、3）。每位玩家的每个游戏及整轮成绩分别保留“最佳＋最近三次”的并集，每类最多四条，重合时去重。四榜公开浏览，每页 20 人，总榜可展开原轮次三项用时。表结构与实施说明见 [排行榜计划](./docs/ranking-implementation-plan.md) 和 [实施报告](./docs/ranking-implementation-report.md)。

首页介绍区右侧提供“我的通关记录”窗口，手机上位于介绍下方。登录后可切换整轮、扫雷、照明、数独，查看自己的最佳及最近三次用时和通关时间；整轮最佳附三关明细。通关保存后自动刷新，也可手动刷新。未登录时可从窗口打开登录，退出或换号立即清空旧账号记录，读取失败可重试。

开发阶段可在**专用开发数据库**环境设置 `DEV_QUICK_COMPLETE_ENABLED=true` 并重启后端，启用各关“开发验收：一键通关”。按钮只完成当前关，随后按正常保存、解锁和结算流程验收。默认关闭；正式环境保持 `false`，测试记录不导入正式库。该功能集中在 `frontend/src/dev-quick-complete.js` 及对应配置/标记处理，便于后续移除。

各页左下角提供全局“音乐：开/关”，设置在当前标签页的页面跳转间保持。最后一关成功保存后，点击“开始结算”播放 `frontend/assets/audio/victory.mp3`，来自用户提供的 `花亦落心亦冷 - PVZ胜利音效.mp3`；每轮只播放一次，关闭结算或返回首页停止，静音时不补放。浏览器禁止自动播放时，等待用户点击或键盘操作后重试，隐藏页面暂停播放。

背景音乐的循环、音量、胜利音期间暂停及切页位置恢复逻辑已具备，但**背景素材尚未接入**：用户指定的 `backmusic-墨澜音 - 阿尔法脑波音乐 (记忆力提升).ncm` 是加密封装，浏览器不能直接播放。需提供同曲可播放的 MP3/M4A/FLAC 后放入静态音频目录，并设置 `frontend/src/music.js` 的 `BACKGROUND_URL`；当前为 null，不请求缺失文件。背景曲尚未完成播放验收。

## 本地预览

完整登录运行方式见 [后端运行与部署](./backend/README.md)：配置 MySQL、执行 Flyway 后，在项目根目录运行 `python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8001 --workers 1 --limit-concurrency 32`，打开 `http://127.0.0.1:8001/`。Python 依赖与环境示例位于 `backend/`。

只预览静态页面时，仍可在 `frontend` 目录运行 `python -m http.server 8000`，但静态服务器没有登录 API，不能完成真实登录或进入需要登录的关卡。

## 测试

在 `frontend` 目录运行 `npm test`。测试使用 Node.js 内置测试工具，不需安装依赖。

后端使用 `python -m unittest discover -s backend/tests -v`。真实 MySQL/Flyway 测试需单独配置专用测试库，否则明确跳过；当前登录、逐关与排行榜浏览器验收使用 `python artifacts/frontend/verify_ranking.py`，验证范围见 [排行榜实施报告](./docs/ranking-implementation-report.md)。完整测试输出应写入日志。

## 版本管理

`.gitignore` 排除敏感本地配置、密钥、虚拟环境、依赖、缓存、日志及浏览器验证生成物。源码、网页素材、测试和 `artifacts/frontend/verify_*.py` 验证脚本纳入版本管理。脱敏配置模板可使用 `.env.example` 等示例文件名提交；后续 Flyway SQL 迁移文件也应提交。

## 部署

Nginx 站点根目录指向 `frontend/`，使用 HTTPS 并将同源 `/api/` 转发到本机单进程 FastAPI；后端和真实配置放在 Web 根目录之外。Flyway 在维护窗口单次执行后退出。宝塔、Nginx、systemd 以及低资源配置模板位于 `backend/deploy/`，具体步骤见 [部署说明](./backend/README.md)。切换前备份原配置与文件，先验证后切换。

当前没有服务器登录信息和域名，尚未部署；真实 MySQL/Flyway 及 2 核/2GB 服务器资源验收状态见 [实施报告](./docs/login-implementation-report.md)。
